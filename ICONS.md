# Moon Icons System

Moon-Style includes a complete SVG icon pipeline: cache management, CLI, visual UI, and Vite plugin.

## Architecture

```
~/.moon-icons/              ← Global cache (git clone of Solar-Icon-Set)
  Icons/SVG/
    Bold/
      Arrows/
        Alt-Arrow-Down.svg
    Broken/
    Linear/
    Line Duotone/
    Bold Duotone/
    Outline/
    Colored/

~/.moon-icons-status.json   ← Download status: downloading | done | failed

project/
  src/assets/icons/qaseh/   ← Project icons (configured via moon.config.json)
    outline/                ← Default variant (plain names)
      key.svg               → sprite ID: "key"
    bold/                   ← Non-default variant (suffixed names)
      key.svg               → sprite ID: "key-bold"
    colored/
      key.svg               → sprite ID: "key-colored"
  public/icons/sprite.svg   ← Built sprite (auto-generated by Vite plugin)
  src/design-system/icons/
    names.ts                ← Auto-generated type-safe icon names
```

## Cache Download

On first run, the system automatically:

1. Checks `~/.moon-icons-status.json` for download state
2. If not `done`, clones `Solar-Icon-Set.git` → `~/.moon-icons/`
3. Records icon count and marks `done`
4. Seeds sample Iconify collections (Phosphor, Tabler, etc.)

**Resilient**: If download is interrupted, next run auto-cleans and retries.
**Concurrent-safe**: PID-based lock prevents duplicate downloads.

## Variant-Aware Sprite IDs

When the same icon exists in multiple style folders, the Vite plugin resolves unique IDs:

| Folder               | Icon File | Sprite ID          |
| -------------------- | --------- | ------------------ |
| `outline/` (default) | `key.svg` | `key`              |
| `bold/`              | `key.svg` | `key-bold`         |
| `colored/`           | `key.svg` | `key-colored`      |
| `line duotone/`      | `key.svg` | `key-line-duotone` |

Usage: `<Icon name="key" />` or `<Icon name="key-bold" />`

## CLI Commands

```bash
# ── Browse ──
yarn moon icons:groups                         # List all available groups
yarn moon icons:list                           # List all icons (across all groups)
yarn moon icons:list "Arrows"                  # List icons in a specific group

# ── Add Icons ──
yarn moon icons:add "Users" --style=Outline                           # Add one group
yarn moon icons:add "Users" "Time" "Security" --style=Outline         # Add multiple groups
yarn moon icons:add "Arrows/Alt-Arrow-Down" --style=Bold              # Add a single icon
yarn moon icons:add --style=Bold                                      # Add ALL icons for a style

# ── Visual UI ──
yarn moon icons:ui                             # Open visual UI (port 8293)
```

> **Note**: Targets can be mixed — groups and individual `Group/Icon` paths in the same command.

```json
  }
}
```

## For AI Agents

When a user asks to add icons:

1. **Browse groups**: Run `yarn moon icons:groups` to see available groups
2. **Add by group** (preferred): Run `yarn moon icons:add "Group1" "Group2" --style=Outline`
3. **Add individual icon**: Run `yarn moon icons:add "Group/Icon-Name" --style=Bold`
4. The Vite plugin auto-rebuilds the sprite with variant-aware IDs
5. Use `<Icon name="icon-name" />` (outline) or `<Icon name="icon-name-bold" />` (bold variant)

### CRM / Default Project Core Groups

For a standard project, these groups cover all essential needs:

```bash

  "Messages, Conversation" "Like" "Shopping, Ecommerce" \
  "Map & Location" \

```

### Iconify (Web Icons)

If an icon is not in the Solar cache, the UI supports:

1. **Iconify API**: Search via the UI's "Find Icons Online" links or use the URL input
2. **SVGL**: Brand logos (React, Vue, Docker, AWS, etc.) are auto-seeded into `Colored/SVGL/`
3. **SVGRepo / Simple Icons / Google Fonts**: Paste the SVG URL into the UI's URL input

The server downloads, sanitizes, auto-detects style, and saves to both cache and project.
