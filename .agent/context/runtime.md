# Moon Runtime

**`Moon`** is the default export from `moon-style`. It's a singleton object providing theme switching and dynamic color management at runtime.

## Theme Management

### `Moon.init(theme?: Theme): void`

Initializes the theme system. Resolution order:

1. Explicit `theme` argument (if provided)
2. `localStorage.getItem("theme")`
3. `matchMedia("(prefers-color-scheme: dark)")` → `"dark"` or `"light"`

Internally calls `Moon.setTheme()` with the resolved theme.

> **SSR guard:** All Moon methods except `onThemeChange` check `isBrowser` (`typeof window !== "undefined"`) and return silently on the server.

### `Moon.setTheme(theme: Theme): void`

1. Persists `theme` to `localStorage`
2. Removes old theme class from `document.documentElement`
3. Adds new theme class to `document.documentElement`
4. Updates `Moon.currentTheme`
5. Fires all registered listeners

### `Moon.onThemeChange(cb: (theme: Theme) => void): () => void`

Registers a listener. Returns an unsubscribe function.

Multiple listeners supported — stored in `Moon._listeners` array. Unsubscribe filters by reference equality.

### `Moon.currentTheme: Theme`

The currently active theme string.

## Dynamic Colors (CSS Custom Properties)

All color methods set both `--{key}` (hex value) and `--rgb-{key}` (comma-separated RGB) on `document.documentElement.style`.

`hexToRGB()` handles both 3-digit (`#abc`) and 6-digit (`#aabbcc`) hex strings → `"r, g, b"`.

### `Moon.setColors(colors: { [key in Color]?: string }): void`

**Replaces** all dynamic colors. Old keys not in the new `colors` object are removed from the DOM. Tracked in module-level `dynamicColors` object.

### `Moon.updateColors(colors: { [key in Color]?: string }): void`

**Merges** into existing dynamic colors — `dynamicColors = { ...dynamicColors, ...colors }`. Then re-applies all `dynamicColors` to the DOM.

### `Moon.setColor(key: Color, value: string): void`

Sets a single dynamic color on the DOM. Does not track in `dynamicColors`.

### `Moon.removeColor(key: Color): void`

Removes `--{key}` and `--rgb-{key}` from `document.documentElement.style`.

### `Moon.removeColors(colors?: Color[]): void`

Removes specific keys from DOM and `dynamicColors`. If no argument, removes all dynamic colors.

## Generated Types (`Moon.Types.ts`)

Auto-generated by the builder from `moon.config.json`:

```ts
export const themes = ["light", "dark"] as const;
export type Theme = (typeof themes)[number];
export const colors = ["primary", "secondary", ...] as const;
export type Color = (typeof colors)[number];
```

Imported by `lib/index.ts` for type-safe `Theme` and `Color` parameters.
